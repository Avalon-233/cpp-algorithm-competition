# C++ 算法竞赛代码仓库

个人算法竞赛练习代码集合，包含各 OJ 平台的题解。

## 📁 目录结构

```
├── luogu/          # 洛谷 (Luogu) 题解
├── PTA/            # 拼题A (PTA) 题解
├── xmuoj/          # 厦大 OJ (XMUOJ) 题解
├── 3月转信航萌新赛(26)/
├── 4月转信模拟(26)/
└── 五一模拟(26)/
```

## 🛠️ 环境

- **语言**: C++
- **编译器**: MinGW-w64 (GCC)
- **系统**: Windows 11

## 📝 命名规范

- 洛谷题目: `luoguP题号.cpp` (如 `luoguP1020cpp.cpp`)
- PTA 题目: `pintia题号.cpp`
- 厦大 OJ: 见 `xmuoj/` 目录

## 📌 备注

- `.exe` 等编译产物已通过 `.gitignore` 排除
- 代码仅供学习参考，部分题目可能有多种解法
